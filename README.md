Welcome to WorldX!

About WorldX:
    - It's a multiplayer game
    - game genres: Top-down 2D Survival Adventure
    - For players that like to automatize yours bots and program them in Python
    - For just PCs

How to setup your client:
    - download client zip folder from releases.
    - unzip zip folder into folder on your computer
    - open terminal inside unzipped folder
    - type command: pip install -r libraryRequirements.txt
    - open your code editor
    - open main.py file from unzipped folder
    - connect to server
    - have fun playing :)

How to setup your server:
    - download server zip folder from releases.
    - unzip zip folder into folder on your computer
    - open terminal inside unzipped folder
    - type command: pip install -r libraryRequirements.txt
